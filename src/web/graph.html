Hover any node for a plain-language read-out of its gripper states. Edge label = mode @ speed. Node colour groups by station (first tag). A node is an arm position; the badges are its gripper leaves — the states you may occupy there. The gripper only changes at nodes marked ⇄, never along an edge.

Each station has a home node (heavier border, e.g. deck_home) shown with ▸ N hidden siblings. Click it to fan the station's nodes out from the home node; click again to collapse back to it. Drag nodes to arrange them; positions, open stations and the view are remembered across reopen. The robot's station auto-expands; manual toggling is locked while a workflow holds control.
